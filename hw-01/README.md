# Демо-стенд для показов продукта

Стенд поднимается перед показом и сносится после: между показами он ничего не стоит.
Состав: два веб-сервера nginx в зонах `ru-central1-b` и `ru-central1-d` за сетевым балансировщиком,
сервер приложения без публичного адреса в зоне `ru-central1-b`, выход в интернет у закрытой подсети — через NAT-шлюз.
Все ресурсы называются с префикса `evdokimov-11` и помечены метками `env=<окружение>`, `owner=evdokimov-11`.

## Что нужно заранее

- Yandex CLI, настроенный на свой каталог: `yc config get folder-id` и `yc config get compute-default-zone` отвечают значениями;
- `jq`, `envsubst` (пакет `gettext-base`), `curl`, `ssh`;
- ключ `~/.ssh/id_ed25519.pub` — его cloud-init кладёт пользователю `student` на все машины.

## Поднять, проверить, снести

```bash
./create.sh              # поднять стенд (≈ 3 минуты); повторный запуск досоздаёт только недостающее
./check.sh; echo $?      # 0 — стенд в норме, 1 — что-то не так
./destroy.sh             # снести всё с префиксом (≈ 2,5 минуты)
```

`create.sh` в конце печатает адрес балансировщика: `стенд готов: http://<адрес>`. Страница отвечает `devlab on <имя машины>`.

## Параметры

Порядок приоритета: аргумент → переменная окружения → умолчание варианта.

| Аргумент | Переменная | По умолчанию | Что задаёт |
|---|---|---|---|
| `--web-count N` | `WEB_COUNT` | 2 | число веб-серверов, зоны чередуются |
| `--port P` | `APP_PORT` | 8033 | порт nginx на машинах (балансировщик слушает 80) |
| `--env NAME` | `ENV_NAME` | test | значение метки `env` |
| — | `PREFIX` | evdokimov-11 | префикс имён; `destroy.sh` удаляет всё с ним |

Пример: `WEB_COUNT=3 ./create.sh --web-count 4` поднимет 4 машины — аргумент важнее переменной.

## Если check.sh вернул 1

| Строка с ✗ | Что проверить |
|---|---|
| балансировщик не найден | стенд не поднят — запустите `./create.sh` |
| балансировщик отвечает не 200 | `yc load-balancer network-load-balancer target-states --name evdokimov-11-lb --target-group-id <id>`: все цели UNHEALTHY — nginx не запустился, смотрите `sudo cloud-init status` на машине |
| ответила одна машина | вторая UNHEALTHY: зайдите на неё `ssh student@<адрес>` и `sudo systemctl status nginx` |
| сервер приложения недоступен | у закрытой машины нет выхода в интернет и nginx не поставился: проверьте, что у `evdokimov-11-subnet-a` есть таблица `evdokimov-11-rt`, и пересоздайте машину (`yc compute instance delete evdokimov-11-app`, затем `./create.sh`) |

Если адрес балансировщика недоступен из сети рабочего места (VPN, фильтрация провайдера), `check.sh` сам повторяет
запросы с сервера приложения — он выходит в интернет через NAT и приходит на балансировщик как внешний клиент;
в строке появится пометка `(запрос с app через NAT)`.

## Цена

Час работы стенда ≈ 3,9 ₽, показ на два часа ≈ 8 ₽ (расчёт — в отчёте по ДЗ 1).
Стенд, забытый включённым, стоит ≈ 93 ₽ в сутки: после показа — всегда `./destroy.sh`.
