# ДЗ 1. Стенд для показов

Стенд поднимается перед показом и удаляется после, чтобы не платить за простой.

Что в нём есть:
- два веб-сервера с nginx, в зонах ru-central1-b и ru-central1-d, перед ними сетевой балансировщик;
- сервер приложения без публичного IP (зона ru-central1-b), в интернет ходит через NAT-шлюз.

У всех ресурсов имена начинаются с `evdokimov-11`, и на них висят метки `env=<окружение>` и `owner=evdokimov-11`.

## Что нужно

- настроенный yc (должны отвечать `yc config get folder-id` и `yc config get compute-default-zone`);
- jq, envsubst (пакет gettext-base), curl, ssh;
- ключ `~/.ssh/id_ed25519.pub`: cloud-init кладёт его пользователю `student` на все машины.

## Как запустить

```bash
./create.sh            # поднять стенд, примерно 3 минуты
./check.sh; echo $?    # 0 если всё ок, 1 если что-то не так
./destroy.sh           # удалить всё с префиксом, примерно 2,5 минуты
```

`create.sh` можно запускать повторно: он пропускает то, что уже есть, и досоздаёт недостающее.
В конце он печатает адрес балансировщика, страница должна отвечать `devlab on <имя машины>`.

## Параметры create.sh

Сначала смотрится аргумент, потом переменная окружения, потом значение по умолчанию.

- `--web-count N` / `WEB_COUNT` — сколько веб-серверов (по умолчанию 2, зоны чередуются);
- `--port P` / `APP_PORT` — порт nginx на машинах (по умолчанию 8033, балансировщик слушает 80);
- `--env NAME` / `ENV_NAME` — значение метки env (по умолчанию test);
- `PREFIX` — префикс имён (по умолчанию evdokimov-11). Осторожно: destroy.sh удаляет всё с этим префиксом.

Например, `WEB_COUNT=3 ./create.sh --web-count 4` поднимет 4 машины, потому что аргумент важнее переменной.

## Если check.sh вернул 1

- **балансировщик не найден** — стенд не поднят, запустить `./create.sh`;
- **балансировщик отвечает не 200** — посмотреть `yc load-balancer network-load-balancer target-states --name evdokimov-11-lb --target-group-id <id>`. Если все цели UNHEALTHY, значит nginx не поднялся, смотреть `sudo cloud-init status` на машине;
- **ответила только одна машина** — вторая UNHEALTHY, зайти на неё по ssh (`ssh student@<адрес>`) и проверить `sudo systemctl status nginx`;
- **сервер приложения недоступен** — скорее всего у закрытой подсети нет выхода в интернет и nginx не поставился. Проверить, что у `evdokimov-11-subnet-a` есть таблица маршрутов `evdokimov-11-rt`, удалить машину (`yc compute instance delete evdokimov-11-app`) и снова запустить `./create.sh`.

У меня адрес балансировщика иногда не открывался из-за VPN, поэтому check.sh в таком случае повторяет запрос с сервера приложения (он ходит наружу через NAT). В выводе тогда будет пометка `(запрос с app через NAT)`.

## Сколько стоит

Час работы ~3,9 ₽, показ на два часа ~8 ₽ (расчёт в отчёте). Если забыть выключить, выйдет ~93 ₽ в сутки, так что после показа сразу `./destroy.sh`.
