## Как поднять стенд

Нужны `yc` с профилем и ключом сервисного аккаунта (ключ лежит в `~/.yc-keys/`, в репозиторий не попадает), `jq`, `envsubst`, SSH-ключ `~/.ssh/id_ed25519.pub`.

```bash
bash work-02/create.sh      # сеть, две подсети, машины с nginx, балансировщик
bash work-02/destroy.sh     # снос всего, что начинается с префикса evdokimov-11
```

Параметры варианта 11 записаны в начале скриптов: префикс `evdokimov-11`, слово `devlab`, порт `8033`.
Ключи, токены и пароли в репозиторий не добавляются: `.gitignore` закрывает `*key*.json`, `*.pem`, `*.key`, `.env`.
